# Mechanics

%% One section per mechanic. For large mechanics, create a dedicated page from the Feature template and link it here. %%

## Mechanic list
| Mechanic | Summary | Status |
| -------- | ------- | ------ |
| Scrolling | Horizontal side-scrolling; the player is kept within the visible screen. | Agreed |
| Twin-stick movement and aiming | Move freely; aim and fire in any direction independently. See [[Controls]]. | Agreed |
| Lives and health | The player has a number of lives (hearts) and a health bar per life. Health reaching zero costs a life; no lives left means game over. | Agreed |
| Weapon upgrades | The weapon has upgrade levels raised by pickups. Losing a life drops the weapon **one** level. | Agreed |
| Shield | Pickup granting temporary protection. | Agreed, details open |
| Meteors | Mix of types: some split into smaller meteors when destroyed, others are destroyed outright. | Agreed |
| Enemy waves | Scripted, escalating waves of enemies entering from the right. | Agreed, details open |
| Bosses | One boss at the end of each campaign level; periodic bosses in Endless. | Agreed, details open |
| Scoring | Points for kills; difficulty applies a score multiplier; kill count shown on the HUD. | Agreed, values open |

## Multiplayer readiness
Single player ships first. Game state and input must be separated from presentation so that up to 4-player online co-op with Photon Fusion can be added later. See [[Technical Design]].
